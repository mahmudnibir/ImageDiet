# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting A Vulnerability

Please do not report security vulnerabilities in a public issue. Open a private GitHub security advisory for the repository or contact the maintainer through their GitHub profile:

https://github.com/mahmudnibir

Include:

- A clear description of the issue
- Steps to reproduce it
- The affected browser and operating system
- The potential impact
- A suggested fix, if you have one

Please avoid attaching real private images or personal data. Use a synthetic test file instead.

You can expect an acknowledgement when the report is received and a follow-up after it has been assessed.
