# Code of Conduct

## Our Pledge

We want ImageDiet to be a welcoming, respectful, and useful project for everyone. Contributors should help create an environment where people can focus on improving the software without harassment or hostility.

## Expected Behavior

- Be respectful and considerate.
- Give feedback about ideas and code, not people.
- Welcome different backgrounds and perspectives.
- Assume good intent while addressing impact clearly.
- Keep discussions focused on the project.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, threats, sexualized language, doxxing, and other harmful conduct are not acceptable in project spaces.

## Enforcement

Report conduct concerns privately to the project maintainer through the contact method listed in the repository. Reports will be reviewed fairly and kept as confidential as practical.

Maintainers may remove comments, close discussions, or restrict participation when behavior violates this code.

## Scope

This code applies in project repositories, issues, pull requests, discussions, and other spaces where someone represents ImageDiet.
